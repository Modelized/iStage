Help

Setup iStage, find tips, and get help with common issues.

What is KLCK?

KLCK (Kustom Lock Screen Maker) is an Android app for creating and displaying custom lock screens.

It lets you build a Lock Screen using text, images, widgets, animations, notifications, media information, device data, and other interactive elements.

KLCK is also used to load, edit, and display iStage.

What is iStage?

iStage is a customizable iOS-inspired Lock Screen preset for KLCK.

It recreates the look and behavior of the iOS Lock Screen on Android, with features such as Dynamic Island, widgets, notifications, media controls, Live Activities, animations, and customization options.

iStage is provided as a .klck preset file and is opened through KLCK.

Most iStage settings can be changed through Globals in KLCK without editing individual elements.

How do they work together?

KLCK is the app that runs the Lock Screen.

iStage is the preset that defines how the Lock Screen looks and works.

iStage runs through KLCK, so KLCK needs to be installed first.

Before setting up iStage, you need to install and configure KLCK.

Install KLCK

First, download and install the KLCK App.

KLCK can be downloaded from Google Play or from Kustom’s official website.

If you use the Google Play version, KLCK Pro is required to import external presets such as iStage. Kustom also provides an AOSP version that does not require Pro.

Set up Kustom storage

When you open KLCK for the first time, choose a folder that Kustom can use for its files.

Kustom creates and manages several files and folders inside the selected storage location, so using an empty folder is recommended.

A simple setup is to create a new folder named Kustom at the top level of Internal Storage and select that folder when KLCK asks for a storage location.

For example:

Internal Storage/Kustom

Using a separate folder keeps Kustom files organized and makes them easier to find later.

Permissions

KLCK needs access to some Android features for iStage to work correctly.

The permissions you need depend on the features you use. KLCK may request access to:

  • Display over other apps to show the custom Lock Screen
  • Notifications for notifications, media information, and music controls
  • Location for weather, sunrise and sunset times, and other location-based information
  • Files and media for accessing local images and other files
  • Other device information when a feature requires it

You do not need to enable every permission at once. KLCK will request permissions when they are needed.

Background activity

KLCK needs to remain active in the background to display and update the Lock Screen correctly.

Allow KLCK to run in the background and remove it from battery optimization.

On many Android devices, this setting can be found under:

Settings → Apps → KLCK → Battery

Set KLCK to Unrestricted, Allow background activity, or the equivalent option available on your device.

If your device has a separate Battery optimization setting, exclude KLCK from optimization.

The exact names and locations of these settings vary between Android devices and manufacturers. Kustom recommends removing the app from battery optimization so it can continue running normally.

Keep the system Lock Screen enabled

iStage does not replace Android’s secure Lock Screen.

Keep your normal PIN, password, pattern, fingerprint, or other screen lock enabled. KLCK displays iStage over the Android Lock Screen, while Android continues to handle authentication and device security.

If you have not finished setting up KLCK, complete the previous Getting Ready section before continuing.

Once KLCK is ready, you can download and apply iStage.

Download iStage

The latest version of iStage is available from the Releases page on the iStage website.

You can also download iStage directly from GitHub Releases.

Download the .klck file for the version you want to use. Do not extract or rename the file before importing it into KLCK.

Import the preset

Open KLCK and select Import, and choose the iStage .klck file you downloaded.

KLCK will copy the preset into its storage and add it to the preset library. Now the iStage preset should be shown in the Library tab.

Load iStage

After the import is complete, find iStage in the Library tab and select it.

KLCK will open the preset in the editor.

If Android or KLCK asks for an additional permission while loading iStage, allow it if the permission is required for the feature you want to use.

Enable the Lock Screen

Importing and loading the preset does not automatically enable KLCK’s Lock Screen.

Open the side menu in the KLCK editor and turn on Lock Screen. Kustom requires this toggle to be enabled manually before a KLCK preset is shown on the device Lock Screen.

Check the Lock Screen

Turn the screen off and wake the device again.

iStage should now appear before the Android system Lock Screen and show its initial Setup screen.

Continue to Personalizing iStage to complete the initial setup.

If iStage does not appear, stays on the default KLCK screen, or disappears after a short time, check the Troubleshooting section.

After applying iStage for the first time, the Onboard screen will appear on the Lock Screen.

Complete the initial setup before using iStage normally. When setup is finished, iStage will show a Setup Summary with your selected options.

Open the Lock Screen Carousel

Touch and hold the Lock Screen to open the Lock Screen Carousel.

From here, you can:

  • Tap Customize to open the Lock Screen editor
  • Tap the + button to open Wallpaper Gallery 2

Tap Customize from the Lock Screen Carousel to open the built-in editor.

The editor lets you customize the main elements of the Lock Screen:

  • Date & Inline Widget
  • Clock
  • Widgets
  • Wallpaper appearance
  • Shortcuts

The Date & Inline Widget, Clock, and Widgets are arranged from top to bottom in the editor.

Tap each area to open its editor and change the available options.

The wallpaper controls and shortcuts are located below them.

Date & Inline Widget

Tap the date area to change the inline widget.

Inline widgets can show information such as weather, calendar events, alarms, and other supported data. It also includes a customizable World Clock with your preferred city and time zone.

Clock Composer 4

Tap the clock area to open Clock Composer 4.

You can change:

  • Font
  • Color
  • Material
  • Size

Clock Composer 4 includes expanded font styles, color palettes, clock materials, and size controls to use the smaller clock.

Wallpaper controls

The controls below the main editor are used to adjust the current wallpaper and its appearance.

Open the More ··· menu for additional options.

Use dark UI elements overrides supported Lock Screen elements with a darker appearance.

Use it when a bright wallpaper makes the default light elements difficult to see.

Shortcuts

The shortcut controls are located at the bottom of the editor.

You can replace the standard Lock Screen controls with other supported shortcuts for faster access to the functions you use most.

Wallpaper Gallery 2

Tap the + button in the Lock Screen Carousel to open Wallpaper Gallery 2.

Wallpaper Gallery 2 includes curated stock wallpapers and lets you create up to 5 custom photo wallpapers using your own images.

Changing a wallpaper changes the background of the current iStage Lock Screen. It does not create a separate Lock Screen configuration.

Other personalization options

iStage also includes additional controls for:

  • Focus modes and custom profiles, including custom profile icons
  • World Clock, including a custom city and time zone
  • Music player volume, with an optional live volume indicator
  • Preset details, which can be viewed for backing up, rebuilding, or transferring your configuration to another device.

You can return to the Lock Screen Carousel at any time by touching and holding the Lock Screen.

Settings that are not available through iStage’s built-in editor, including device-specific display adjustments and direct Globals controls, are covered in the next Advanced Customization section.

Most settings can be changed directly from the iStage editor.

For settings that are not available there, you can change iStage directly through Globals in KLCK.

Open Globals

Open the KLCK App and load iStage in the editor.

Open the Globals tab to view the settings used throughout the preset.

At the top level, iStage uses three main folders:

  • bg — Wallpaper settings
  • config — User-configurable settings
  • dev — Internal settings used by iStage

The dev folder contains globals used by iStage’s internal systems, formulas, animations, and interface states. Editing these values can affect how the preset works, so leaving this folder unchanged is recommended.

After changing a Global, save the preset in KLCK to apply the change.

Change Setup options later

Some settings shown during the initial Setup can also be changed directly through Globals.

Corner radius

Go to:

config/glass/radius

Change the value to adjust the corner radius used throughout iStage. The preset recommends values between 20 and 100.

Status Bar & Dynamic Island position

Go to:

config/status/position

Change the value to move the Status Bar and Dynamic Island vertically to better match your device. The recommended range is 10 to 40.

Dynamic Island size

Go to:

config/status/island

Choose:

  • New — iPhone 18 Pro series size
  • Old — iPhone 17 Pro series and older size

This changes the width of the Dynamic Island.

Time format

Go to:

config/date/timefmt

Use:

  • 0 — 12-hour
  • 1 — 24-hour

The selected format should match the time format used by your device.

Battery percentage

Go to:

config/status/battery

Use:

  • 0 — Hide
  • 1 — Show

This controls the percentage shown inside the battery indicator.

Notification previews

Go to:

config/notishow

Use:

  • 0 — Hide
  • 1 — Show

This controls whether notification content is shown on the Lock Screen.

Live Activities

Live Activity controls are located in:

config/liveact

Each supported Live Activity has its own switch. The available modules may vary between iStage builds. In the attached build, the F1 module is controlled by f1status.

Backgrounds

Wallpaper settings are stored in the bg folder.

Change the active wallpaper

Go to:

bg/type

Enter the ID of the wallpaper you want to use.

Wallpaper IDs are organized by category:

  • 1X — iOS wallpapers
  • 2X — iPhone wallpapers
  • 3X — Photo wallpapers

For example, 21 selects bg21, while 34 selects the fourth custom photo wallpaper.

You can check the ID of a wallpaper by opening its folder under bg and looking at the name of its Bitmap Global.

Assign custom photo wallpapers

Go to:

bg/photo

There are five custom photo slots:

  • bg31
  • bg32
  • bg33
  • bg34
  • bg35

Open one of these Bitmap Globals and use Pick Image to assign your photo.

To display that photo, set bg/type to the matching number.

For example:

bg31 → bg/type = 31

Custom clock color

Clock Composer 4 provides the standard clock color controls. A fully custom color can be set through Globals.

Go to:

config/clock/custom

Open the Color Global and choose the color you want to use.

The custom color is used when Custom is selected as the clock color.

Custom World Clock

To change the city and time zone used by the World Clock, go to:

config/date

Change these two Globals:

  • tztext — The city or time zone label displayed on the Lock Screen
  • tzcode — The IANA time zone code used for the World Clock

For example:

tztext = NYC

tzcode = America/New_York

Use a valid IANA time zone code for tzcode.

Custom Focus profile

The icon and color of a custom Focus profile can be changed from the iStage editor.

The profile name is changed through Globals.

Go to:

config/focus/text

Enter the name you want to display.

After changing the name, also open:

config/focus/bgwidth

and adjust the value to match the length of the new text.

KLCK does not automatically resize the Focus background when the text changes. If the value is too small, the text can extend outside the background. If it is too large, unnecessary empty space will appear around the text.

Carrier & Signal tweaks

Additional Status Bar settings are available under:

config/status

Carrier name

config/status/carrier

Enter a custom carrier name to replace the detected carrier text.

Signal strength

config/status/sigbars

Use 1 to 5 to manually set the displayed cellular signal strength.

Use 0 to disable the custom override.

Network type

config/status/network

You can override the displayed cellular network type with:

  • LTE
  • 4G
  • 5G

The preset uses GPRS as the no-custom setting.

Liquid Glass

Additional Liquid Glass settings are available under:

config/glass

You can manually adjust:

  • blur — Blur intensity
  • brighten — Brightening applied to the material
  • dim — Additional dimming
  • radius — Corner radius

These settings change the appearance of Liquid Glass elements across iStage.

radius is also available during the initial Setup, while the other values are intended for finer manual adjustment.

System accent color

Go to:

config/color/accent

to change the system accent color used by supported iStage elements.

If iStage does not work as expected, check the issue below before changing individual elements or Globals.

Try restarting KLCK first

If iStage suddenly stops working even though the setup is correct, restart KLCK and clear its cache.

  1. Touch and hold the KLCK App icon.
  2. Open App info.
  3. Tap Force stop.
  4. Open Storage or Storage & cache.
  5. Tap Clear cache.
  6. Open KLCK again and check the Lock Screen.

This can fix temporary KLCK issues where iStage does not appear, stops updating, or becomes unresponsive.

Do not use Clear storage or Clear data unless you intend to reset KLCK.

iStage does not appear

Open the KLCK App and check that iStage is loaded in the editor.

Open the side menu and make sure Lock Screen is enabled. KLCK does not enable its Lock Screen automatically after a preset is imported.

Also check that:

  • Display over other apps is allowed for KLCK
  • KLCK is allowed to run in the background
  • KLCK is excluded from battery optimization
  • The preset has been saved after loading

Turn the screen off and wake the device again after changing these settings.

The default KLCK screen appears instead of iStage

Open KLCK and go to the Library tab.

Select iStage again and save the preset.

If iStage is not shown in the Library, import the .klck file again. Make sure the file has not been extracted or renamed. Kustom supports .klck and .klck.zip preset files and recommends importing them without decompressing them.

If you installed KLCK from Google Play, make sure KLCK Pro is available before importing an external preset.

iStage disappears or stops updating

Android may stop KLCK when it remains in the background.

Open your device settings and set KLCK to Unrestricted, Allow background activity, or the equivalent option provided by your device. Also remove KLCK from Android battery optimization.

Kustom needs to remain active to update information such as the clock, battery state, weather, and other live data. Kustom recommends excluding the app from battery optimization for this reason.

Some manufacturers apply additional background restrictions. Check any Auto Start, Background Usage, Sleeping Apps, or similar settings available on your device.

The Onboard screen is stuck or buttons do not respond

Make sure KLCK is still running and has permission to display over other apps.

If touch controls stop responding:

  1. Remove KLCK from battery optimization.
  2. Open KLCK Settings and check its background and notification settings.
  3. Restart KLCK.
  4. Turn the screen off and wake the device again.
  5. Restart the device if the problem continues.

Kustom also recommends using Forced Notification Mode when touch actions fail on devices that aggressively restrict background apps.

Do not change values inside the dev Globals folder to bypass the Onboard screen.

The Lock Screen is cropped or does not fill the display

Make sure Android allows KLCK to use the entire display, including the area around the camera cutout or notch.

Some devices provide a per-app Full screen, Camera cutout, or similar display setting. Set KLCK to use the full screen where available. Kustom specifically recommends enabling full-screen access when KLCK cannot draw behind a notch or cutout.

If the Lock Screen fills the display but individual elements are still misaligned, use the display controls described in Advanced Customization section to adjust the Status Bar position, Dynamic Island size, and corner radius.

Notifications do not appear

Make sure Notification access is enabled for KLCK.

Android uses this access to provide notification information to Kustom. It is also required for several media-related features.

Also check that:

  • The source app is allowed to send notifications
  • Notification previews are enabled in iStage if you want notification content to be shown
  • KLCK is not being stopped in the background

Music information or controls do not work

KLCK uses Android notifications to detect active media players.

Make sure Notification access is enabled, then start your music app and play something at least once. The media player should also have an active notification in the Android notification panel.

If KLCK detects the wrong media app, open the KLCK settings and set your preferred app under Preferred Music Player.

If album artwork is missing, check whether the music app has an option that prevents album artwork from being exposed to the Lock Screen or media notification.

Weather or location information is missing

Check that KLCK has Location permission and network access.

Kustom uses location data for weather information and for calculations such as sunrise and sunset times. A fixed location can also be configured in Kustom if you do not want to provide continuous location access.

After changing the location settings, allow some time for weather information to refresh.

Carrier or signal information is missing

KLCK may require phone status access to read information such as the current carrier, cellular connection type, and signal state. Kustom requests this permission when a preset uses those values.

If your device does not provide the information correctly, iStage also provides manual Carrier & Signal overrides under Advanced Customization.

Live Activities do not update

Live Activities that use online information require an internet connection.

Make sure KLCK has network access and is allowed to continue running in the background.

Battery restrictions can prevent data from refreshing while the device is idle.

If only one Live Activity is affected, the external data source used by that activity may also be temporarily unavailable.

Custom photos do not appear

If you assigned a photo through Globals, check that the image is still available to KLCK.

For the five custom Photo slots, make sure the selected bg/type value matches the Bitmap Global being used:

bg31 → 31

bg32 → 32

bg33 → 33

bg34 → 34

bg35 → 35

These slots and the bg/type selector are defined separately in the preset.

A persistent KLCK notification appears

This notification may be used to keep Kustom active in the background.

Kustom recommends removing the app from battery optimization. When Kustom can remain active normally, the persistent notification may no longer be required. The notification itself can also be disabled through Android notification settings.

The Android Lock Screen still appears

This is normal.

KLCK displays iStage over the Android system Lock Screen and does not replace Android’s secure authentication screen. Your PIN, password, pattern, fingerprint, or other authentication method is still handled by Android.

Because of this, the system Lock Screen may appear during the unlock process depending on your device and security settings.

iStage is slow or laggy

The new iStage uses a large number of Globals, animations, visual effects, and interactive elements.

On lower-end devices, this can cause slow animations, delayed touch responses, high memory usage, or severe lag.

Try closing unnecessary background apps and make sure KLCK is not restricted by battery or memory management.

If the new iStage is too heavy for your device, you can also try iStage 18, which has a simpler feature set and may run better on less powerful hardware.

Performance can still vary depending on the device, Android version, and KLCK version.

iStage still does not work

Update KLCK to the latest available version and restart the device.

If the problem continues, re-import a fresh copy of the latest iStage .klck file and load it again.

Avoid modifying anything in the dev Globals folder while testing.

Some problems may be caused by the Android version or the device manufacturer’s Lock Screen behavior.

  • Samsung One UI — iStage generally works correctly across most versions.
  • Google Pixel and AOSP-based ROMs — On Android 16 QPR2 and later, KLCK may occasionally fail to appear immediately when the screen wakes. Turning the screen off and on again may be required before the Lock Screen appears. Disabling full-screen Always-On Display may reduce how often this occurs.
  • Other Android systems — Compatibility may vary depending on the manufacturer’s Lock Screen, background activity, and battery-management behavior.

If none of the steps above resolve the issue, the problem may be caused by a system-level limitation that KLCK or iStage cannot fully control.

When reporting an issue, include your device model, Android version, KLCK version, iStage version or build number, a screenshot or screen recording, and a short description of what happens and when it happens.
